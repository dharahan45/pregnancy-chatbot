# Pregnancy Chatbot 🤰💬

## 📌 Project Description
This is a simple AI-based Pregnancy Chatbot designed to help pregnant women by answering common questions related to pregnancy, health, nutrition, and care.

The chatbot provides quick and basic guidance and is intended for educational purposes only.

## 🎯 Objectives
- Provide instant answers to pregnancy-related questions  
- Support expecting mothers with reliable information  
- Improve awareness about prenatal care  

## 🛠️ Technologies Used
- Python  
- Natural Language Processing (NLP)  
- HTML / CSS (if web-based)  
- Flask (if used for backend)

## ⚙️ Features
- Answers pregnancy-related FAQs  
- Easy to use chatbot interface  
- Text-based interaction  

## 🚀 How to Run the Project
1. Clone the repository  
2. Install required libraries  
3. Run the main Python file  
4. Open the chatbot interface
